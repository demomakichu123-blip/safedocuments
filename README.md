# 🔒 SafeDocuments

সব গুরুত্বপূর্ণ ডকুমেন্ট ডিজিটালি সংরক্ষণ করার অ্যাপ — NID, পাসপোর্ট, ড্রাইভিং লাইসেন্স, জন্ম নিবন্ধন, ওয়ারেন্টি কার্ড। একটাই ফাইল — কোনো সার্ভার লাগে না, সব ডেটা তোমার ফোনেই থাকে।

## যা আছে

- **ডকুমেন্ট ভল্ট** — ক্যাটাগরি: NID, পাসপোর্ট, ড্রাইভিং লাইসেন্স, জন্ম নিবন্ধন, ওয়ারেন্টি কার্ড, অন্যান্য
  - নাম, ডকুমেন্ট নম্বর, ইস্যুর তারিখ, মেয়াদ শেষের তারিখ, নোট
  - ডকুমেন্টের ছবি/স্ক্যান সংযুক্ত করা যায়
  - add / edit / delete, খোঁজা (search) + ক্যাটাগরি ফিল্টার
- **ডকুমেন্ট স্ক্যানার** — "স্ক্যান করো" চাপলেই ফোনের ক্যামেরা খুলবে; ছবি অটো ছোট করে (সর্বোচ্চ ১০০০px, JPEG) সংরক্ষণ করা হয়, যাতে জায়গা কম লাগে। গ্যালারি থেকেও ছবি নেওয়া যায়।
- **মেয়াদ শেষের রিমাইন্ডার** — ৩০ দিনের মধ্যে মেয়াদ শেষ হচ্ছে এমন ডকুমেন্ট হলুদে, আর মেয়াদ শেষ হয়ে গেছে এমনগুলো লালে দেখায় ("X দিন বাকি" সহ)। ড্রাইভিং লাইসেন্স আর ওয়ারেন্টি কার্ডও এখানে আসে।
- **PIN সুরক্ষা** — প্রথমবার খুললে ৪ সংখ্যার PIN দিতে হয়; এরপর প্রতিবার অ্যাপ খুলতে PIN লাগবে। সেটিংস থেকে PIN বদলানো যায়, আর 🔒 লক বোতামে এখনই লক করা যায়।
- **ব্যাকআপ** — সব ডকুমেন্ট (ছবিসহ) JSON ফাইলে ডাউনলোড করো, ফোন বদলালে সেই ফাইল দিয়ে ফিরিয়ে আনো।
- **স্টোরেজ মিটার** — কতটুকু জায়গা ব্যবহৃত হচ্ছে দেখায়; প্রায় শেষ হলে সতর্ক করে।

## ফোনে অ্যাপ হিসেবে বসানো (PWA — App Store লাগবে না)

3. Home screen-এ নীল আইকন আসবে — ওটা খুললেই ফুলস্ক্রিন অ্যাপের মতো চলবে, অফলাইনেও খুলবে

## আসল iOS / Android অ্যাপ (Capacitor — Mac লাগবে iOS-এর জন্য)

`ios/` আর `android/` ফোল্ডারে আসল native প্রজেক্ট আছে (Capacitor 8, app id `com.safedocuments.app`)।

Mac + Xcode থাকলে (iOS):
1. Repo clone করো, `npm install` দাও
2. `npm run sync` দাও (ওয়েব ফাইলগুলো প্রজেক্টে কপি হবে)
3. `ios/App/App.xcworkspace` খুলে iPhone কানেক্ট করে **Run** চাপো

Android-এর জন্য Android Studio-তে `android/` ফোল্ডার খুলে Run চাপো।

নোট: `.apk` / `.ipa` ফাইল শুধু Mac/Android Studio দিয়ে বানানো যায় — এই Linux মেশিনে Gradle build চলে না। ওয়েব অ্যাপে কিছু বদলালে root-এর ফাইল বদলে `npm run sync` দিয়ে আবার sync করো।
